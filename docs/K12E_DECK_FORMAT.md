# Bản đồ format deck K12E Conrod (HyperMesh 14.0 → Abaqus Standard 3D)

Tài liệu khảo sát **đầy đủ** cấu trúc và format của bộ deck K12E conrod — nền tảng để viết parser/validator.
Khảo sát 2026-07-10 qua nội dung file thật. Deck tổng ~1.115.959 dòng (master Comb đã ghép).

---

## 2. Mesh solid (`ndelm`)

Header xuất: `ABAQUS Input Deck Generated by HyperMesh Version : 14.0.134-HWDesktop`.

| TYPE | Component (= ELSET) | Format dòng |
|---|---|---|
| `C3D8I` (hexa 8 node incompatible-mode) | Bolt_Hexa, Lower, PistonPin, Upper | id + 7 node dòng đầu (kết `,`) + node 8 dòng sau |
| `C3D6` (penta 6 node) | Bolt_Penta | 1 dòng 7 số |
| `C3D10M` (tetra 10 node modified) | Bush, Cap1, Cap2, Cap_Sholder, Cap_Tetra, Conrod1, Conrod2, Conrod_SE_Bore, Conrod_Tetra | id + 7 node dòng đầu (kết `,`) + 3 node dòng sau |

- `*NODE`: `id, x, y, z` — có số khoa học (`4.841483105E-14`), có dạng rút gọn (`-20.0`).
- **Dải ID KHÔNG đồng nhất** — elem Cap1 9 chữ số (`100142294`), Cap2 7 chữ số (`3050580`) trùng khoảng số với node (`3088104`). Không dùng ID suy ra loại entity.
- `*SOLID SECTION` ×15 (mỗi component 1 section): material `STEEL` (E=205800, ν=0.3, ρ=7.85e-09 — mm/tấn/s) cho Bolt/Bush/KnockPin/Lower/PistonPin/Upper; `STEEL_rod` (E=213000, ρ=7.823e-09) cho nhóm Cap/Conrod.
- `*ELSET, ELSET=ALL_MASSIVE_ELEMENTS`: danh sách phẳng 8 ID/dòng (không GENERATE) — đích của DLOAD quán tính.
- `*SURFACE, NAME=s_*, TYPE=ELEMENT` với data **`elemID, S#`** (từng element một dòng, mã mặt S1–S6 hexa/penta, S1–S4 tetra). VD `s_Awscap`: `3009010, S3`. → lỗi "chọn thiếu 1 element" = thiếu đúng 1 dòng.

## 3. Face numbering (cho module check contact)

- `C3D8I`/`C3D8`/`C3D6`: bảng mặt S1–S6 chuẩn Abaqus (C3D6 dùng S1–S5).
- `C3D10M`/`C3D10`/`C3D4`: bảng mặt tetra S1–S4 chuẩn.
- Membrane: `SPOS`/`SNEG` theo pháp tuyến element.

## 4. Mesh membrane (`Conrod1_membrane_7@.inc`)

```
*SYSTEM            ← block rỗng (reset hệ tọa độ global)
*NODE, SYSTEM=R    ← node 500000–517999 (~18k node), vành mặt ổ trục
                     (x=∓7.2 cố định, y≈−22.5, bán kính ≈22.5)
*ELEMENT, TYPE=M3D4, ELSET=MR_7
                   ← quad membrane 1 dòng/element; elem ID TRÙNG dải node ID (500000+)!
*MEMBRANE SECTION, ELSET=MR_7, MATERIAL=MAT_MR_7
 0.001             ← dày 0.001 = lớp da giả chỉ để trung chuyển tải
*MATERIAL, NAME=MAT_MR_7
*ELASTIC, TYPE=ISO ← viết tắt của ISOTROPIC! E=210000, ν=0.3
```

**Xương sống truyền tải của model:**
node `5xxxxx` → elset `MR_7` → surface `S_CONTACT_7` (định nghĩa **inline trong master**: `MR_7, SNEG`) → `*TIE, NAME=CONTACT_7, POSITION TOLERANCE=0.5` với `S_BE_SURFACE` (group ID 3 trong HM) → solid.
CLOAD 18k node/step đổ vào node membrane, truyền qua tie vào bore. **Tie này thiếu/thủng = 18k lực trôi tự do.**

## 5. Master files

Master **không phải mục lục thuần** — chứa inline:
- `*SURFACE` (`S_CONTACT_7`), `*TIE` (`CONTACT_7`)
- `*NODE` reference: 900002 (0,0,0); 900003/900004 (∓16.985, 0, 142.8); riêng Comb thêm 900005–900034 (30 node **cố ý trùng tọa độ** tại ∓16.985,0,142.8 — mỗi node cho 1 góc quay) + 101/201 (0,±29,−7.16)
- `*NSET _T-const1..15` (mỗi nset 2 node 9000xx)
- 30× `*Coupling, constraint name=Pin_const#, ref node=9000xx, surface=s_Pinpis` + `*Distributing, weighting method=UNIFORM`
- 15× `*Transform, nset=_T-const#, type=R` — hệ tọa độ xoay theo góc trục khuỷu
- Toàn bộ `*STEP`

### Comb_6000rpm — cấu trúc step

| Step | Nội dung |

### Conrod1_BUSH — bài chạy trước

- Include **cp0** (Comb dùng **cp1**).
- Step `Step1_Bore-Set`: `*Model Change, type=CONTACT PAIR, remove` (`s_SEbore,s_pinse`); `*contact interference` `s_SEbore2,s_SErod,-0.047`; BC piston pin.
- Kết quả feed sang Comb: `*INITIAL CONDITIONS, TYPE=STRESS, FILE=Conrod1_BUSH.odb, STEP=1`.
- **⚠ Chuỗi phụ thuộc giữa 2 lần chạy:** mesh đổi → phải chạy lại BUSH trước → mới chạy Comb. Quên = Comb nhận stress của mesh cũ, sai âm thầm.

## 6. Diff cp0 vs cp1 (biến thể contact — giống nhau ~95%)

| Mục | cp0 (BUSH) | cp1 (Comb) |
|---|---|---|
| `s_SEbore ↔ s_pinse` | CONTACT PAIR, clearance **comment** (0.01) | CONTACT PAIR, `*clearance ... VALUE=0.0075` **ACTIVE** |
| `s_SEbore2 ↔ s_SErod` | **CONTACT PAIR** (+ interference −0.047 làm trong step BUSH) | ***TIE*** (bush đã "set" xong) |
| Còn lại | ~12 CONTACT PAIR (bolt/cap/aws) + 2 TIE bolt + `*Coupling BE_const` (Crank_Pin ↔ s_bore) + khối KnockPin **comment toàn bộ** | như cp0 |

Logic nhất quán có chủ đích — nhưng sửa 1 file quên file kia là lỗi không nhìn thấy bằng mắt. Validator: diff 2 file theo cấu trúc (pair-by-pair), không diff text.

## 7. Surface — 3 dạng trong deck

1. **`elemID, S#`** — từng element + mã mặt (các `s_*` trong ndelm). Dạng chi tiết nhất.
2. **`elset, SNEG|SPOS`** — theo elset membrane (`S_CONTACT_7` = `MR_7, SNEG`).
3. **Analytical**: `*surface, type=REVOLUTION, name=...` (data: trục + START/LINE profile) + `*rigidbody, refnode=..., analyticalsurface=...` (srf2, chữ thường).

## 8. Setup đang TẮT bằng comment (inventory hiện trạng — xác nhận có chủ đích)

- `bndry.inp`: 5 dòng BC (`nd_bolt1_head`, `nd_bolt2_head` dof 1&3, `nd_se_conrod` 1,2).
- cp0/cp1: nguyên khối KnockPin (2 CONTACT PAIR + 2 TIE `s_npinbore*`), các dòng `**clearance`.
- cp2: `**clearance ... v=<cl_se>` — **`cl_se` KHÔNG được định nghĩa trong par.inp** → bỏ comment là fail. 
- Master: `**INCLUDE srf1/elemset` (file không tồn tại), `**contact interference,SHRINK`.

## 9. Bẫy parser (bắt buộc xử lý)

1. Keyword **hoa/thường lẫn lộn**: `*CONTACT PAIR` / `*surface` / `*Coupling` / `*contact interference`.
2. Tham số **viết tắt**: `TYPE=ISO` ≡ `ISOTROPIC` → prefix match.
3. **Continuation**: dòng data kết `,` → record tiếp dòng sau (C3D8I, C3D10M).
4. `*NODE` có tham số (`SYSTEM=R`, `NSET=`).
5. **Element ID và node ID trùng dải số** (membrane) — không suy loại từ ID.
6. `*PARAMETER` + tham chiếu `<tên>` trong data (`<Fax>`, `<mc_interferense>`, `<cl_se>` chỉ trong comment).
7. Comment `**` ba loại: ghi chú, `**HMNAME GROUPS <id> <tên>` (map ngược group ID HyperMesh), keyword bị comment.
8. Semantics `OP=NEW` trong BOUNDARY/CLOAD/DLOAD: xóa và thay toàn bộ — bảng BC/tải hiệu lực đổi theo step.
9. `*SYSTEM` block rỗng, `*PREPRINT`, `*HEADING`, `*AMPLITUDE`, `*RESTART` — parse-and-ignore an toàn.
